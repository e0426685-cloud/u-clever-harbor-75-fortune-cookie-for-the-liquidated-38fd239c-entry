## The fortune

> Your lucky numbers are 0, 0, 0, and the margin call you ignored at midnight.

## How it works

`main.py` (Python 3, standard library only) writes the single fortune-cookie
line to `/output/entry.txt`, then makes the file world-readable so the grader
can read it. A small `validate()` checks the text is non-empty, at most 160
characters, and at most 20 words, matching the competition gate.

Run it with:

```sh
python3 main.py
```
